# 英検準1級 即答ドリル

和文を見て英語で答える瞬発英作文アプリ（1日3文。ナレーションの日と Q&A の日を交互に）。

- お題を見たまま、画面の中で録音 → Gemini が**言ったとおりに**書き起こし（文法の誤りを直さない）
- 添削：できているところ → 誤りを全部 → 直した文 → 発音 → 次の一手 → 模範文
- 自分の声を波形で聞き直し（タップで頭出し・なぞって区間ループ・0.75/0.5倍速）
- 記録は Google Apps Script 経由でスプレッドシートへ。毎晩、右腕AIの学習ログと日英ドリル台帳に書き写す

## 設定
Gemini APIキーと記録の送り先URLは、アプリの「設定」から入れる。**どちらもそのブラウザの localStorage にだけ保存され、このリポジトリには含まれない。**
